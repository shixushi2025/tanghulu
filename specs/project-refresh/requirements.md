# 更新范围与验收

在已有未提交改动上完善 Astro + Cloudflare 内容精选站，不改换技术栈。本轮直接落实用户授权的项目更新；新增素材仍待用户提供，先补现有条目的编辑内容。

1. 浏览：访问首页时展示精选、专题和完整收藏；分类、排序、分页可通过 URL 分享；无 JavaScript 时仍可浏览。
2. 详情：打开有效条目时显示正文、阅读导航、相关推荐和评分；不存在的条目返回 404。
3. 安全：未认证请求不可修改内容；跨站写请求被拒绝；登录尝试限流；输入类型、长度、日期和 URL 均校验；敏感响应不缓存。
4. 数据：同一匿名访客每小时最多计一次浏览，并发写入不丢失；评分可更新且不产生孤立数据；数据库不新增原始 IP。
5. 性能：列表不读取正文，列表有界分页，静态资源可缓存，搜索输入节流。
6. 质量：自动测试覆盖验证、认证、SQL 并发、API 和桌面／移动浏览；构建与类型检查通过。
7. 交付：提供系统设计、测试用例、安全边界、内容维护和部署步骤；不操作生产数据库。
