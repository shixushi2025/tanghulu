# 测试设计与验收

## 可重复执行

```sh
npm ci
npx playwright install chromium
npm run verify
npm audit
```

推荐 Node.js 24 LTS。`.github/workflows/ci.yml` 在 push / PR 时执行相同校验，并在失败时保留浏览器 trace；本轮已验证本地命令，尚未在 GitHub 触发远端 CI。单元测试使用 Node 内置 test runner、SQLite 内存库和 esbuild；不依赖在线账户。浏览器测试使用真实 Chromium、编译后的原生 Cloudflare Worker 与 Static Assets、本地 D1/KV，数据在临时目录中隔离并清理，不读写生产。

## 发布前仍需的环境验收

- 在预览域名验证真实 Cloudflare 绑定、HTTPS Secure Cookie 与边缘 IP 覆写。
- 检查生产备份、迁移历史以及 `0005`／`0006` 跳过的后台自定义内容。
- 用实际目标设备检查 iOS Safari／Android WebView；本轮浏览器自动化仅覆盖 Chromium。
- 若要承诺容量，需在隔离环境定义并实测 p95 延迟、错误率与 D1 预算。本轮没有对生产施压，也不宣称负载容量指标。
- 无障碍自动与人工检查可继续扩展屏幕阅读器、真实封面与长标题等场景。
