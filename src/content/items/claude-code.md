## 它能解决什么问题

Claude Code 可在终端等开发环境中协助实现功能、排查问题和运行开发工具。关键价值是围绕仓库上下文完成多步骤工作；结果仍需要通过 diff、测试和实际运行来验证。

## 适合谁

- 需要处理现有代码库的开发者
- 想把重复开发步骤交给助手的人

## 第一次怎么用

1. 在可回退的分支里打开一个小项目。
2. 给出可复现问题、影响文件和验收标准。
3. 审查改动，再运行测试；确认后才提交。

## 可以试的任务

「复现这个表单提交错误，先说明原因，再做最小修复。保留现有交互，并用一个回归测试证明修复。」

## 选择前要了解

官方说明提供 Claude 订阅或 Anthropic Console 等接入方式，并非只能使用 API Key。执行命令、访问文件和外部服务前要检查授权范围；方案与额度以账户为准。
