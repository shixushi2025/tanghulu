## 它能解决什么问题

DeepSeek 的开发者文档提供 API 调用说明及兼容接入方式。普通使用者可从对话入口开始；开发者则需要分别核对 API 的模型标识、认证和计费，不宜把网页使用体验等同于接口能力。

## 适合谁

- 需要辅助分析问题与代码的人
- 希望接入模型 API 的开发者

## 第一次怎么用

1. 先用一个已知答案的问题测试表达方式。
2. 要求列出关键假设和需要核实的数据。
3. 若接入 API，再独立验证格式、错误处理和用量。

## 可以试的任务

「解释这个 SQL 为什么出现重复行，给一个最小数据例子，再提出修改方式和验证查询。」

## 选择前要了解

不要将历史 R1 等模型名视为当前默认型号。API 文档会更新模型别名和退役安排；推理文字是生成内容，不能替代事实来源或可执行测试。
