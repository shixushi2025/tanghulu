## 它能解决什么问题

Visual Studio Code 官方文档提供安装、语言支持、调试和开发工作流指引。先配置好项目的运行、测试和格式化方式，再选择必要扩展，可以避免工作区变得难以维护。

## 适合谁

- 正在学习编程的人
- 需要统一项目开发环境的开发者

## 第一次怎么用

1. 打开一个项目，确认如何安装依赖和运行。
2. 配置语言支持与必要的格式化工具。
3. 通过一次断点调试或测试执行理解工作流。

## 可以试的任务

为一个小项目写清启动、测试和调试步骤，让另一台电脑也能照着完成相同操作。

## 选择前要了解

扩展需要单独检查发布者和权限。AI 服务、远程开发和云端功能可能涉及额外账户或费用，不等于编辑器的所有功能都无条件可用。
